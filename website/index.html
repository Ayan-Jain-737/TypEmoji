Native Architecture

Engineered Specifically for the Modern Linux Desktop

No heavy JavaScript runtimes. No 200MB background processes. Built from the ground up in modern C++23 and Qt 6 with dedicated Wayland portal integration.

Wayland & X11 Hybrid Core

Automatic runtime detection of compositor protocols. Employs KGlobalAccel on KDE Wayland, XDG Desktop Portals on GNOME, IPC bindings for Sway and Hyprland, and native XGrabKey under X11.

KGlobalAccel XDG Portal ydotool wtype XTest

Clipboard-Safe Injection

If an environment requires synthetic clipboard injection, TypEmoji snapshots your clipboard state prior to injection and restores your exact clipboard history within microseconds.

Zero Clobber Instant Restore MIME Preservation

Pre-Warmed Singleton Daemon

TypEmoji idles silently as a lightweight background daemon consuming under 14MB RAM. When triggered, the picker window pops up in under 4ms without cold-boot overhead.

CLI & Window Managers

CLI Flags, Tray Controls & WM Integration

Designed for window managers like i3, bspwm, Sway, and Hyprland. Bind EmojiTyper --toggle directly to any custom key combination in your configuration file.

CLI Flags & Window Manager IPC Commands
Command Flag Action Config Binding Example (Hyprland / i3 / Sway)
EmojiTyper --toggle Toggle picker visibility bindsym $mod+period exec EmojiTyper --toggle
EmojiTyper --show Open panel at current cursor / caret coordinate bind = $mainMod, E, exec, EmojiTyper --show
EmojiTyper --reload Hot-reload emoji database & configuration bindsym $mod+Shift+e exec EmojiTyper --reload
EmojiTyper --quit Gracefully terminate background daemon process bindsym $mod+Escape exec EmojiTyper --quit
